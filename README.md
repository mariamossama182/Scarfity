# Scarfity 🧣
**Scarfity** is a fully functional e-commerce platform dedicated to scarves. This project focuses on building a "strong foundation" in web development by combining clean frontend design with a structured backend logic.

## 🚀 Features
- **Product Gallery:** Interactive display of products with filtering options.
- **Admin Dashboard:** A private area for managing products, prices, and orders.
- **Shopping Cart:** Seamless user experience for adding and managing items.
- **Contact System:** Integrated with **EmailJS** for direct communication.
- **Responsive Design:** Optimized for all screen sizes.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript.
- **Backend:** PHP (Modular architecture).
- **Database:** MySQL.
- **Tools:** EmailJS, XAMPP.

## 📌 Project Philosophy
This project was built with a focus on **clean code** and **maintainable logic**, ensuring that the system is scalable for future features (like moving to React.js).

## 🔧 How to run it locally
1. Clone the repository.
2. Import the provided `database.sql` file located in the `Scarfity_DB` folder into your local PHPMyAdmin.
3. Place the project folder in your `htdocs` (if using XAMPP).
4. Update `config.php` with your local database credentials.
5. Access it via `localhost/Scarfity`.
